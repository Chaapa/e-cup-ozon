# Архитектура контура обучения с LLM

```text
BAD-вход ──> зафиксированная Qwen3.5-4B + два prompt ──> порог

organizer FLV train ──┬──> контрольные точки control LoRA ─┐
                      ├──> контрольные точки candidate LoRA ─> OOF-признаки ─> CatBoost-selector
                      ├── 100 проверенных отношений train ───┤
                      ├── 200 синтетических пар OpenRouter ──┤
                      └── 100 экземпляров / 62 mass key train ──> только candidate
```

Дублирующиеся компоненты organizer train закрепляются за одной складкой. Каждая
OOF-группа полностью исключается из соответствующей обучающей траектории.

Попарный обучающий сигнал имеет малый вес относительно CE.
